# Python Rock Paper Scissors

A simple Rock-Paper-Scissors game made with Python.

## Features

- Player can choose Rock, Paper, or Scissors
- Computer makes a random choice
- Shows the choices using emojis
- Determines the winner
- Detects ties
- Allows the player to play again
- Handles invalid choices

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Run the `rock-paper-scissors.py` file.
4. Choose `r`, `p`, or `s`.
5. Follow the instructions in the terminal.
